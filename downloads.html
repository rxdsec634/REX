Checksum

Compare the hash

If the printed hash differs from the one on the build, don't run it.

# Windows certutil -hashfile "REX Setup 0.2.8.exe" SHA256 # Linux / macOS sha256sum rex_0.2.8_amd64.deb
Debian family

Install with apt

Use apt, not dpkg -i — it pulls the dependencies for you.

sudo apt install ./rex_0.2.8_amd64.deb rex # desktop tools need xdotool (X11) # or ydotool under Wayland
First run

Three steps and you're working.

STEP 01

Add a provider

Settings → Providers. Paste a key — it's sealed in the OS credential store. Or skip it: if Ollama is running, REX finds it on its own.

STEP 02

Open a project

New session, then pick a folder. Every file and shell operation is scoped to it, and the status bar shows which folder is live.

STEP 03

Ask for something real

"Find where we verify JWTs and fix anything unsafe." REX searches, reads, proposes a diff — and waits for you.
