A few useful answers

DECODE
THE DETAILS.

Do I choose the model?＋

Yes. REX supports cloud providers, local runtimes such as Ollama, and custom OpenAI-compatible endpoints. Configure your provider in the agent.

Does local-first mean fully offline?＋

Your workspace and execution live on your machine. Cloud models and web tools still need a network connection. Local models can keep inference on your own hardware.

Can I use REX in my terminal?＋

Yes. Install @rxdsec/rexcli globally with npm and start it with rex. The CLI includes browser tools, queue controls, and automatic updates from version 0.3.11.

Where do I start?＋

Visit Downloads for the desktop builds or the CLI install command, then connect your model provider. Account access and plan details are explained on the Plans page.
