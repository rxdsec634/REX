Why REX

Built different, on purpose.

Keys never leave your OS

Provider keys are sealed in the platform credential store, not a dotfile. REX talks to providers straight from your machine — no proxy in the middle.

Agentic, not chatty

Streaming responses, native tool calling, automatic context compaction and append-only session history. It plans, acts and checks its own work.

Any model, even offline

23 providers — cloud, local and any OpenAI-compatible endpoint. Run Ollama or a local GGUF and REX works with the network cable pulled.

A browser it drives

A real browser view inside the window: navigate, read the accessibility tree, click, type and screenshot — while you watch.

It can use the computer

Screenshot, click and type through native backends on each OS. Never auto-allowed: every desktop action asks, every time.

It remembers your rules

A REX.md at the project root is read into every session, so conventions you explain once survive restarts and model switches.
